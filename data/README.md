# Data package

This directory contains derived research artifacts only. It does not contain raw DAPT-2020 traffic.

## Included

- `silver_pilot/DAPT2020_MAST_batch_001_provisional_resolved_labels.xlsx`: 240-unit resolved stance pilot.
- `manifests/DAPT2020_MAST_annotation_analysis.json`: annotation-analysis summary.
- `taxonomy/dapt2020_mast_annotation_guidelines.json`: stance/aspect annotation definitions.

## Label status

The pilot is an **AI-assisted single-reviewer silver-label resource**. Two blinded AI annotation passes were followed by a separate AI-assisted resolution pass. It must not be described as independently adjudicated human gold data.

## Restrictions

The workbook is supplied for private internal reproducibility while upstream redistribution terms are being verified. Do not redistribute it or use it to reconstruct the original DAPT-2020 dataset. See `DATA_USE_NOTICE.md`.
